# 双世界本地试玩版（2026-10-18）

## 运行

需要 Node.js 24 或更新版本。在 StockNeko 目录执行：

```powershell
npm run build
npm start
```

浏览器打开 http://127.0.0.1:8765 。先选择原有本地玩家，然后在世界选择页注册本地服务账户（名称和至少 8 位密码）。这不会覆盖旧玩家。

- **游戏叙事世界**：创建独立存档即可玩，使用明确标注的虚构行情。
- **真实股票世界**：界面、账户与研究工具可用；未配置真实行情时，没有随机证券价格，禁止成交与真实回测。
- **返回本地旧存档**：继续原有离线交易、久留美剧情、心理恐怖、生活、挑战等。下方增加持仓小屋与学习、基金、策略入口。
- GitHub Pages 只承载静态离线版，不能运行 SQLite 或账户服务。

## 本次实现

1. 持仓工具栏独立占位、自动换行，避免实体按钮挡住表格；按钮使用离线毛笔字体，报价数字保留等宽字体。
2. 登录后的双世界选择、深色专业世界与浅紫薄荷叙事世界；返回旧存档入口；可拖动导航排序、折叠明细、涨跌配色、日 K 与成交量缩放及全屏。
3. 服务端独立存档：创建、读取、自动保存、命名、重命名、十个手动快照、恢复快照、删除确认、回收站恢复；每账号最多二十个活动存档。
4. 基金：名称/简介/风格/单股上限，独立账户、三类模拟客户、申购赎回、净值/份额、基金交易、T+1、费用、现金、回撤、收益及客户反馈。
5. 策略：MA/RSI/MACD/布林带/量比/动量条件，AND/OR 两条件、仓位、止盈止损、日期区间、费用与滑点、初始资金、保存编辑复制、可执行回测和交易记录。前日信号、次日开盘；曲线、年化、最大回撤、夏普、胜率与时间切分结果。
6. 八种交易行为画像，公开主要评分规则及画像变化历史。少于三笔成交显示观察期。
7. 买入约定可选填六项；按委托关联实际成交，条件触及标记，卖出前展示原约定，允许修改或取消。
8. 月报可重复计算，交易/资产/回撤/最佳最差交易/约定统计，月份历史及 PNG 导出；服务端跨月自动生成上月报告。
9. 原创 SVG 持仓猫咪按证券代码绑定，情绪、命名、每日陪伴经验、历史记录、清仓纪念册与三种房间装饰。养成不改变价格或资金。
10. 十类百科，解释、示意图、小测验、来源、搜索、收藏、独立学习进度。首次答对给猫咪经验，重复答题无重复奖励。

## 数据与迁移

延用现有 SQLite `records(bucket,key,value)`，新增 `world-slots` bucket，无破坏性 SQL 迁移。每个记录包含 `user`、`world`、`id`、`revision`、资金状态、功能数据、请求幂等记录与快照。User/Session 沿用现有 users/sessions，好友和消息仍由原 API 管理，不复制跨世界资产。

- `story` 状态由服务端加载现有 StockGame，再通过委托/推进命令更新。
- `real` 状态通过已有 Broker 和行情适配器校验；未连接真实源时拒绝委托。
- 更新事务使用 SQLite `BEGIN IMMEDIATE`，匹配 revision，避免多窗口静默覆盖。
- 幂等请求编号重复不会再次扣钱，相同编号不同参数会拒绝。
- 客户不能通过 API 上传资金/持仓状态。服务端查询必须匹配当前登录用户。
- 浏览器 IndexedDB 旧存档不导入、不删除，保留独立入口。旧游戏新增 features 字段只在本地使用，不能当作可信资金状态导入服务端。
- 本机数据库默认 `data/stock-meow.sqlite`。后端静态路由仅允许游戏页面，`.env`、数据库与源码不能经 HTTP 下载。

## 实际接口

新增 `/api/session`、`/api/worlds`、`/api/worlds/:id`、`/market`、`/history`、`/action`、`/recover`。复用原登录、好友、消息、市场接口。

现有真实行情适配器为 **Tushare Pro**：`stock_basic`、`trade_cal`、`rt_k` 或 `daily`、`stk_limit`；真实回测另外要求 `adj_factor`。配置项见 `.env.example`：TUSHARE_TOKEN、MARKET_PROVIDER=tushare、MARKET_DATA_LICENSED=true、QUOTE_DELAY_SECONDS 等。密钥只放服务端。

本次测试没有用户行情密钥，**未连接或验证真实在线行情**。不会声称真实成交或数据授权已经开通。接口依据：[Tushare 日线文档](https://tushare.pro/document/2?doc_id=27)；交易规则资料：[上交所规则入口](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/)。

## 本版边界（不视为完整商业版验收）

- 没有云服务器，因此未部署公网多设备同步；同一服务账户的后端存档机制已经具备，跨设备实测和公网安全部署未完成。
- 没有真实行情 API，真实世界停留在可配置的专业工作区；实时数据、分钟线、财务与全部板块/历史生效规则的联调未完成。专业世界仅沿用已有可用规则，不宣称覆盖全部证券特殊情形。
- 回测支持单证券、两条件组合及固定观察周期；不是自由拖拽多节点策略引擎。真实回测遇到复权因子变化直接拒绝，不冒充已正确处理分红送转。退市样本池、滚动样本外、市场指数同期比较、复杂成交排队模型未实现。年化与夏普以 252 日计算，短样本可能失真。
- 基金份额采用百万分之一份、金额采用分；净值展示由比值计算。申赎有极小份额舍入误差。基金尚无自定义头像、可配置指数基准、自动月度基金报告、完整申赎排队系统；专业基金交易暂限主板/创业板整手规则。
- 月报没有真实市场基准时显示“缺少同期数据”；报告导出 PNG，未实现 PDF。
- 人格评分是透明的游戏启发式，尚未实现完整计划执行率与亏损后行为因果分析。
- 持仓猫咪已有原创矢量外观和基本对话，尚无丰富骨骼动画、独立长篇 NPC 章节。既有久留美与恐怖剧情仍在原有本地版本。
- 两世界未加入新的专属背景音乐；原有特效/声音设置保留。
- 本地离线功能保留浏览器资金模型，与服务端权威账户明确分开。

- `work/v8/world-ui.js`、`world-ui.css`：世界选择、工作区、旧版小屋与遮挡修复。
